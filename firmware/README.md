# Inkwash C++ firmware

ESP-IDF 5.5.5, C++17 and LVGL 9 for the Zectrix Note 4.

Build, flash and test instructions are in the [project README](../README.md).
Fonts are in `assets/`; the persistent storage layout is `partitions.csv`.
Application code is in `main/`, hardware-free tests in `test/`, and the
e-paper driver and LVGL in `components/`.
